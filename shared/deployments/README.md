# Deployments

Add chain-specific JSON only after an actual deployment. Do not invent addresses.

`local-31337.json` was generated by an actual ephemeral Anvil deployment and smoke-tested against that running node. Its deterministic local addresses are not persistent public deployments.

`base-sepolia.json` must be created only by a successful Base Sepolia broadcast and verified with the configured chain before it is committed. Deployment files contain public addresses and metadata only—never signing material or private RPC URLs.
